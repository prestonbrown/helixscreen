# Unit Art Milestone 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. CLAUDE.md § Verification Cadence overrides per-task review: tags while building, one review and one `make land-gate` at the finish.

**Goal:** A host-side art kit and skill, proven on the ACE Pro and one harder unit, feeding baked art on the dryer page, tinted thumbnails on overview cards, and per-unit shells on the live N-lane tray.

**Architecture:** `scripts/unit_art/` is a dev-machine Python kit and the single source of each unit. It generates committed images and one committed C++ geometry table. C++ selects, places, stretches and tints; devices never run Python.

**Tech Stack:** Python 3 with `rsvg-convert`, pytest (`tests/python/`), C++17 subset safe for firmware headers, LVGL 9.5, Catch2.

**Spec:** `docs/devel/plans/2026-11-08-unit-art-design.md`. Mockups: `docs/superpowers/iso-art-spike/` (local, throwaway, reference only).

**Not in this plan:** spool rotation, airflow, remaining units, toolheads. Each gets its own plan once the skill is frozen here.

## Global Constraints

- Art camera: yaw 27 degrees, pitch 20 degrees, all units. Tray camera: `include/ams_tray_projection.h`, unchanged in its projection.
- Spools match `spool_canvas`/`spool_vents` values. Air holes on full-size art only.
- No manufacturer wordmarks. One art set for light and dark themes.
- ACE Pro and Pro 2 share one drawing.
- ESP32 stays on logos and compiles none of this: new sources are not added to `firmware/helixscreen-esp32/components/helixapp/app_srcs.txt`.
- Unidentifiable hardware (such as Happy Hare reporting only firmware) and undefined units keep today's logo and generic tray.
- The simple tier is the existing `helix::ui::reduced_effects()` (`include/filament_tube_stroker.h`), not a new mechanism. Vendor names appear only in the one lookup module.
- Full tier bar on MIPS: no visible frame drop on spool repaint; at most 2 points added idle CPU over the 6 to 7 percent animations-off baseline.
- Comments: no archaeology. Timestamps on added debug logs. spdlog only.
- `HELIX_HEADLESS=1 SDL_VIDEODRIVER=dummy` for every app run; pin socket and config dir per CLAUDE.md.

## Review Focus

- A unit with 1 lane, or more lanes than fit: tray stays inside its container and caps never overlap the first or last spool. Test in Task 5.
- Theme switched while the tray or art is on screen: shell colours and art update without a revisit. Test in Task 5.
- Disconnected or `absent` unit with art: art shows the same faded or disabled state the card already uses. Test in Task 4.
- Empty lane, or unset (zero) filament colour: lane tint is hidden, never drawn black. Test in Task 4.
- A multi-unit rig with mixed defined and undefined units: each unit resolves independently. Test in Task 4.
