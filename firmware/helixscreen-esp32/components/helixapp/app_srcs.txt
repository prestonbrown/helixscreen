# helixapp source manifest — the curated Core+AMS app core compiled UNMODIFIED
# from ../../src for Xtensa. Exact repo-relative paths, one per line.
#
# LINE FORMAT — CMake reads this file with
#     file(STRINGS app_srcs.txt APP_SRCS_REL REGEX "^[^#].*\.(cpp|c)$")
# so a path line MUST start at column 0 and END at the suffix. A trailing
# `# reason`, or even a trailing space, makes the regex miss the line and the
# file is silently DROPPED from the build — the link then fails ~25 min into
# esp32-build CI on a line that reads as present. Leading whitespace is the
# mirror image: the regex matches and CMake builds the path `<repo>/ src/…`.
# Put explanations on their own `#` comment line above the path (this file's
# whole derivation ledger is written that way). scripts/check_esp32_app_srcs.py
# rejects any other shape.
#
# `# MOCK:` lines are commented-out documentation of the desktop mock set, NOT
# build input. Only ams_backend_mock.cpp is actually compiled under
# CONFIG_HELIX_MOCK_PRINTER, and CMakeLists.txt names it directly (MOCK_SRCS) —
# the rest are unlinkable on ESP32. See the MOCK_SRCS comment there.
#
# DERIVATION (see esp32p4-task-5-report.md for the full ledger):
#   Base: Plan 2 native-audit manifest (478 src/lib/assets entries, proven
#         shim-portable + link-clean with the audit stub set).
#   -69   files removed: subsystems gated OFF for the v1 Core+AMS cut
#         (label printers, camera/QR, gcode 2D/3D rendering, bed-mesh 3D +
#         nozzle renderers, calibration panels, timelapse viewer, mock backend).
#   +8    override/ audit copies replaced by the REAL src/ file (the audit's
#         ESP tweaks are now main-tree #if HELIX_PLATFORM_ESP32 fixes, or were
#         superseded by the Plan 2 asset_path/token-table seams).
#   +13   real src/api Moonraker command surface + MoonrakerManager that the
#         audit had STUBBED — helixnet's EspMoonrakerClient makes the transport
#         real, and MoonrakerAPI drives it through the IMoonrakerClient
#         interface (send_jsonrpc), so the command layer is portable.
#   +1    generated token table (src/generated/theme_token_table.cpp).
#   +1    src/api/moonraker_api_controls.cpp, un-stubbed once its HTTP half was
#         split into moonraker_api_power.cpp (E-STOP and temperature control were
#         no-ops on-device until then).
#
#   The deltas above are the narrative of how this set was chosen; they do NOT
#   sum to the total and never did. The base they subtract from is the audit
#   manifest, which has been edited independently since, and this file has since
#   dropped the 34 assets/fonts/*.c entries it shipped with (fonts are staged as
#   binary assets now, not compiled here). Do not trust a running total — count
#   what CMake actually reads:
#       grep -cE '^[^#].*\.(cpp|c)$' app_srcs.txt
#   Today that is 443 src/ + 3 lib/ = 446 source files.
#
