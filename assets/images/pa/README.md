# Pressure advance reference pictures

The tuners' "where to look" card shows three samples per pass: Right, Too little and
Too much advance. Each is the wall seen edge-on from above, across the one speed change
the pass judges, with the transition at 45% of the width.

| Files | Pass |
|---|---|
| `lin_corner_{right,too_little,too_much}.png` | Linear K: a corner from above |
| `nl1_left_*.png` | Nonlinear pass 1: medium into slow on the left face |
| `nl2_*.png` | Nonlinear pass 2: fast into slow (both faces fail the same way) |
| `nl3_front_lit_*.png` | Nonlinear pass 3: the same, half the size, under a side light |
| `nl_pass_{1,2,3}_thumb.png` | The nonlinear setup's tower thumbnail per pass: left side, left against front, front lit from the side (the time offset) |
| `nl_pass_front_thumb.png` | The front in ordinary light, for a front-judged tower that isn't the time offset (Bowden's first) |

The samples are 160 x 68 px, the thumbnails 168 x 128 px; the card scales them to fit. They
carry no words, so they need no translation. To replace a drawing with a photo, crop the
photo to the same aspect and view, keep the file name, and keep words out of it.
