# Format:  <exact test case name>  # why

# The exempted cases are all compile-time assertions (see the block at the end).
# The remaining no-assertion findings are real, mostly "X does not crash" /
# "X is safe" tests that call a function and assert nothing. Each should either
# grow a REQUIRE_NOTHROW (which Catch2 does count) or an assertion on the state
# the call was supposed to leave behind. Note SUCCEED() does NOT count: Catch2
# emits no <Expression> for it, so a SUCCEED-only case still reads as vacuous.
# The VACUOUS_MAX ratchet in mk/tests.mk holds the line meanwhile.

# be cleared, hiding that much real headroom.
